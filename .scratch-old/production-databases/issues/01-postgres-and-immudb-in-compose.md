# 01: PostgreSQL and immudb run in the compose stack

**What to build:** `docker compose up` starts a PostgreSQL and an immudb container with healthchecks, named volumes and credentials supplied as secrets. The auth service waits for both to be healthy. Developers can reach both from the host, so tests run against the same containers.

**Blocked by:** None (can start immediately)

**Status:** done

- [ ] PostgreSQL and immudb start healthy from a blank volume
- [ ] Credentials come from secrets, with documented dev defaults generated by an existing make target or script
- [ ] The auth service depends on both being healthy
- [ ] Ports for host access are configurable and bound to localhost
- [ ] `.env.example` lists the new variables
